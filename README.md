# 🤖 Gemini AI Chatbot

My first Generative AI project built using Python and Google's Gemini API.

## 🚀 Features

- Interactive AI chatbot
- Generates responses using Google Gemini
- Secure API key management
- Simple terminal-based interface
- Exit command to stop the chatbot

## 🛠️ Technologies Used

- Python
- Google Gemini API
- Google GenAI SDK
- Python Dotenv


## ⚙️ How to Run

1. Clone the repository.
2. Create a Python virtual environment.
3. Install the required packages:

```bash
pip install google-genai python-dotenv
```

4. Create a `.env` file inside `genai-chatbot/` and add your Gemini API key:

```text
GEMINI_API_KEY=your_api_key_here
```

5. Run the chatbot:

```bash
python genai-chatbot/chatbot.py
```
